# 내 첫번째 아이디어 (My First Idea) ✨

> 모든 위대한 여정은 하나의 작은 영감에서 시작됩니다.

화면 중앙에 웅장한 크기와 신비로운 블루 글로우(Blue Glow)로 **"내 첫번째 아이디어"**를 보여주는 감성적이고 세련된 인터랙티브 웹 애플리케이션입니다.

---

## 🌟 주요 기능

- **중앙 포커스 카드**: 마우스 포인터의 위치에 반응하는 3D 원근 틸트(Tilt) 인터랙션 및 프리미엄 글래스모피즘(Glassmorphism) 디자인
- **블루 앰비언트 & 캔버스**: 별자리(Constellation) 캔버스 파티클 애니메이션과 부드럽게 유영하는 블루 오라 이펙트
- **인터랙티브 스파크**: '영감 불꽃 피우기' 클릭 시 화려하게 터지는 블루/사이언 파티클 버스트 및 Web Audio 화음 사운드 재생
- **아이디어 기록(메모)**: 팝업 모달을 통해 자신의 첫 번째 아이디어를 브라우저 로컬 저장소(`localStorage`)에 영구 저장 및 카드에 표시
- **3대 블루 테마 전환**: 
  - 💎 **Sapphire Blue** (기본): 깊이감 넘치는 웅장한 로열 사파이어 블루
  - ⚡ **Cyber Cyan**: 짜릿하고 청량한 네온 아쿠아 블루
  - 🌊 **Midnight Ocean**: 심해처럼 신비로운 코발트 네이비

---

## 🛠 기술 스택

- **HTML5**: 시맨틱 웹 구조 및 SEO 메타 태그
- **Vanilla CSS**: CSS Custom Properties 디자인 시스템, 글래스모피즘, 반응형 레이아웃
- **Vanilla JavaScript**: HTML5 Canvas 파티클 렌더링, 3D 틸트 수학 계산, Web Audio API 사운드 합성

---

## 🚀 로컬 실행 방법

`index.html` 파일을 웹 브라우저에서 직접 더블 클릭하여 열거나, 로컬 웹 서버를 실행합니다:

```bash
# Python 내장 서버로 실행
python -m http.server 3000
```

웹 브라우저에서 [http://localhost:3000](http://localhost:3000)으로 접속합니다.
